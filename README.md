# Previsão do Tempo

## Projeto:

O projeto tornou-se um site de uso funcional e prático, visando trazer o conhecimento da temperatura máxima, mínima e qual o "céu". As informações são somente do dia da pesquisa feita.

<hr>

- HTML 5
- CSS 3
- JavaScript
